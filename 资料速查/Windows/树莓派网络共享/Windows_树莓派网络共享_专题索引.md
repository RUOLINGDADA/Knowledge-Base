# [技术/网络与嵌入式] Windows 11 与树莓派有线连接专题索引

## 专题结论

推荐拓扑是：Windows WLAN 作为上游，Windows 物理以太网作为 ICS 下游，树莓派通过网线接入。ICS 启用后 Windows 下游地址通常为 `192.168.137.1/24`，树莓派通过 DHCP 获得同网段地址，并使用 Windows 作为默认网关。

网络桥接和 ICS 是两套不同机制：本场景需要的是 ICS；WLAN 加入网桥后，Windows 通常不会在该成员接口上显示 ICS 的“共享”选项卡。

## 最小复现清单

```text
1. WLAN 能上网
2. WLAN 不再是网桥成员
3. WLAN 属性中启用共享，家庭网络连接选物理以太网
4. Windows 以太网查询到实际 ICS 地址
5. 树莓派获得同网段 IPv4 和默认路由
6. 先 ping 网关，再 ping 公共 IP，最后测 DNS
7. 用 ssh 用户名@树莓派IP 登录
```

## 复盘边界

- 本专题记录的是 Windows 11 + Raspberry Pi OS 的常见 ICS 场景；具体菜单名称、网络管理器和默认地址可能因版本、驱动、VPN、Hyper-V/WSL 配置而变化。
- 用户已反馈网络共享成功；命令输出、具体树莓派地址和 SSH 服务状态未在本工作区独立复测，仍应以现场命令结果为准。
